# Подключение анкеты к Google Таблице (UPOP_casting)

Анкета отправляет каждую заявку в Google Таблицу через **Google Apps Script**
(бесплатно, без сервера). Это единственный шаг, который нужно сделать **тебе**
в своём Google-аккаунте — я не могу войти в него за тебя. Занимает ~5 минут.

## 1. Создай таблицу
1. Открой https://sheets.google.com → **Пустая таблица**.
2. Переименуй её (вверху слева) в **`UPOP_casting`**.

## 2. Вставь скрипт
1. В таблице: меню **Расширения → Apps Script**.
2. Удали весь код-заглушку в `Code.gs`.
3. Скопируй **весь** файл [`Code.gs`](./Code.gs) из этого репозитория и вставь.
4. Нажми **💾 Сохранить** (значок дискеты).

## 3. Опубликуй как веб-приложение
1. Вверху справа: **Deploy → New deployment** (Развернуть → Новое развёртывание).
2. Шестерёнка **Select type → Web app**.
3. Настройки:
   - **Execute as:** `Me` (от твоего имени).
   - **Who has access:** `Anyone` (Все). ← обязательно, иначе сайт не сможет писать.
4. **Deploy**. Google попросит разрешение — разреши (Advanced → Go to project → Allow).
5. Скопируй **Web app URL** — он заканчивается на **`/exec`**.

## 4. Впиши URL в сайт
1. Открой `js/main.js`, найди строку:
   ```js
   const SHEET_ENDPOINT = "";
   ```
2. Вставь свой URL:
   ```js
   const SHEET_ENDPOINT = "";
   ```
3. Закоммить и запушь (Vercel задеплоит). Готово — заявки падают в таблицу.

## Проверка
- Открой URL `…/exec` в браузере → должно ответить `{"ok":true,"service":"UPOP_casting",...}`.
- Заполни анкету на сайте → в таблице появится новая строка со всеми полями.

## Что уже решено в скрипте
- **Конкуренция:** одновременные заявки не портят друг друга — каждая запись
  под блокировкой (`LockService`), пишутся строго по очереди.
- **Идемпотентность:** у каждой заявки свой `submissionId`. Повтор/двойная
  отправка/переотправка при плохой сети **не создаёт дубликат** — скрипт видит
  уже записанный id и не добавляет строку второй раз.
- **Красивый формат:** закреплённая жирная золотая шапка, понятные названия
  колонок, дата-время как настоящая дата, галочки `Ha / —` для согласий,
  перенос текста и чередование строк.

## Обновление скрипта потом
Если поменяешь `Code.gs` — снова **Deploy → Manage deployments →** карандаш **→
Version: New version → Deploy** (URL остаётся тем же). Новые колонки в `FIELDS`
подхватятся автоматически при следующей заявке.

## Тексты сайта (админка → Редактирование)
В админке есть вкладка **Редактирование** (uz: **Tahrirlash**): там меняется любой
текст, цифра и дата на upop.uz на каждом языке — Oʻzbekcha, Özbekça, Русский,
English. Правки видны на сайте после обновления страницы, без деплоя Vercel.

- **Где хранится:** лист **`Content`** этой же таблицы (создаётся сам при первом
  сохранении): `Key | Oʻzbekcha (uz) | Özbekça (oz) | Русский (ru) | English (en) | Yangilangan`.
  Заполненная ячейка заменяет текст по умолчанию из `js/content.js`, пустая —
  возвращает его. Пустая ячейка Özbekça — текст берётся из узбекского автоматически.
- **Чтение:** сайт забирает правки по открытому адресу `…/exec?action=content`
  (без пароля, только чтение). Ответ кэшируется до 6 часов и сбрасывается при
  каждом сохранении — у него новый номер версии `v`.
- **Запись:** только из админки, с паролем `ADMIN_KEY` (Project Settings ▸
  Script properties).
- **Разметка** в полях с золотым выделением и ссылками (заголовки, подвал):
  `*слово*` — золотое выделение, `[текст](https://…)` — ссылка (можно `mailto:`
  и `tel:`), перенос строки — новая строка. HTML не нужен: он покажется как текст.
- Правь тексты через админку. Правки прямо в листе `Content` сайт подхватит только
  после следующего сохранения из админки.

**Нужен передеплой.** После обновления `Code.gs`: **Deploy ▸ Manage deployments ▸ ✏️ ▸
Version: New version ▸ Deploy** (URL остаётся тем же). Пока это не сделано, вкладка
Редактирование не сохраняет и просит обновить скрипт, а сайт показывает тексты по
умолчанию. Проверка: открой `…/exec?action=content` → `{"ok":true,"v":"0","c":{}}`.

## Заметки
- Токенов/паролей на сайте нет — Google-доступ живёт только внутри Apps Script.
- Хочешь дублировать заявки в Telegram/на почту — можно добавить в `doPost`
  (скажи, добавлю `MailApp.sendEmail(...)` или вызов Telegram-бота).
